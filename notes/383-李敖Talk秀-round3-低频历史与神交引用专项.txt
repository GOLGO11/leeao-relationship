《李敖Talk秀》第三轮：低频历史与神交引用专项

本轮目标
1. 复核低频历史、政治、文艺、神交引用节点，避免把节目口语切片误当人物。
2. 补回有明确证据的低频人物，尤其是典故、艺术史、电影明星、书籍作者类引用。
3. 修正节目逐字稿里由短名、误字、别名导致的错误归并。

本轮新增或强化的人物
1. 任瑰：作为唐太宗赐醋典故中的唐代大臣进入，分类为政治人物、历史类比引用、神交引用。
2. 任夫人：作为任瑰夫人、吃醋典故中的人物进入，分类为婚姻相关、历史类比引用、神交引用。
3. 杜兰：由《哲学的故事》《文明的故事》作者语境补入，分类为诗文出处、学术、历史类比引用、神交引用。
4. 罗丹、卡蜜儿：由师生恋讨论中的艺术史例子补入，罗丹归文艺音乐、历史类比引用、神交引用；卡蜜儿另加情感。
5. 苏菲亚罗兰、鲍德瑞克：由电影明星例子补入，归文艺音乐、媒体、历史类比引用、神交引用。

本轮新增关系边
1. 任瑰 -> 任夫人：夫妻/吃醋典故引用。
2. 罗丹 -> 卡蜜儿：师生/艺术恋情引用。

本轮清理与归并
1. 清理节目口语切片和泛称：严格说、公告、古话说、国政治、居然有、家来看、家属、家庭生、张三、李四、王五、俞大维等。
2. “张良”在宁恩承、西安事变语境中归并为张学良。
3. “宋希濂”在学校、监狱、明金城、陈美儒语境中归并为辛隆，避免误入历史军政人物。
4. “蔡松坡”归并为蔡锷。

正式重建结果
1. 全库：83 本，4616 章，9145 人，24873 条身份链接，2387 条人物关系边。
2. 《李敖Talk秀》：19 章，476 人，22 条本书手工关系边。
3. 本轮单本临时抽取：423 人，19 章，用于误抽筛查。

验证
1. Python 编译检查通过：scripts/extract_relationships.py。
2. 单本临时抽取通过：.tmp-talk-r3-data / .tmp-talk-r3-exports。
3. 正式全库重建通过，且使用逐本 --book-path。
4. node --check data\relationship-data.js 通过。
5. node --check assets\app.js 通过。
6. 总库人物名重复数：0。
7. CSV 字段保持原格式：姓名、分类、主分类、可信度、出现次数、相关出现、涉及书数、涉及章节数、主要书目、线索。

本轮校对经验
1. 节目逐字稿中“张三李四王五”这类泛称不能因为历史人物库已有同名就进入本书。
2. 高频政治节目文本会把“人物短名”和“句子残片”一起带出，必须结合同段话题判断是否是真人节点。
3. 神交引用不等于排除：只要是李敖用来论证、比喻、举例的真实人物或文学人物，都应进入，但要把分类落在历史类比引用、神交引用或虚拟人物上。
4. 对节目类书籍，来宾/主持/扮演关系与神交引用要分开；同集来宾属于直接接触语境，典故人物属于引用语境。

下一轮建议
进入《李敖Talk秀》第四轮，做“本书收尾前的高频人物身份抽查”：重点看前 80 名人物里是否仍有分类过重、节目角色误判、同名误并的问题，尤其是媒体人、艺人、政治人物和历史类比引用之间的边界。
