《读史指南》第三轮：后两章演义与神话边界校对

本轮目标
专项处理《介绍世界最大的百科全书》和《中国历史演义总说》。这两章不是普通叙事，而是“资料工具书示例”和“历史演义导读”，人物类型混杂：书目作者、索引编制者、说书人、真实历史人物、演义影响下的历史人物、神话宗教人物都在一起，需要细分边界。

主要处理
1. 补入《介绍世界最大的百科全书》中的氏族文献、镜部例证和索引编制者：
   柳芳、吕祖谦、凌迪知、顾炎武、高力士、秦始皇、赵飞燕、宋太祖、窦仪、俞照、泷泽俊亮、牟润孙等。
2. 把“外编”神话人物和神名从普通历史引用中分出：
   盘古、雷公、阎王、江赫沖、闪多归入虚拟人物/宗教人物/历史类比引用/神交引用。
   达摩、刹利帝菩提多罗归入宗教人物/历史类比引用/神交引用。
3. 补入《中国历史演义总说》中的说书史和演义批评人物：
   归庄、王彭、孟元老、尹常、胡适、何义门、尤侗、舒屋山人、梁启超、黄兴等。
4. 补入各朝历史演义段落中的人物群：
   东周秦汉、后汉、三国、两晋南北朝、唐五代宋元明清民国等段落的人物，重点补齐刘禅、孙浩、司马炎、拓跋珪、萧道成、陈霸先、朱全忠、李克用、阿阔台、贵由、蒙哥、王洙、马翌、努尔哈赤、皇太极、顺治、缪荃孙等。
5. 增加别名/规范名：
   孔明 -> 诸葛亮
   赵匡胤 -> 宋太祖
   光武帝 -> 刘秀
   忽必烈 -> 元世祖
   元太祖 -> 成吉思汗
   齐桓 -> 齐桓公
   阿斗 -> 刘禅
6. 新增书内关系边：
   苏轼 -> 王彭，说书史料引述/三国故事反应
   孟元老 -> 霍四究，东京梦华录记载/说三分名家
   孟元老 -> 尹常，东京梦华录记载/说五代史名家
   宋太祖 -> 窦仪，镜部纪事/读书人宰相典故
   朱元璋 -> 李善长、胡惟庸、蓝玉，明初功臣/锦衣卫政治清洗
   梁启超 -> 黄兴，新中国未来记/黄克强预言

校对经验
历史演义类文本不能把“出现于小说/演义”直接等同于“虚拟人物”。曹操、刘备、诸葛亮、关公、刘禅、司马炎等仍是真实历史人物，只是本书中的关系语境属于历史演义和史实辨析；而盘古、雷公、阎王、江赫沖、闪多这类才应进入虚拟/神话宗教边界。
