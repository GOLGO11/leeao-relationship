《要把金针度与人》第四轮：低频尾部压残片

本轮目标
- 不再大幅扩人，重点复核低频人物、字号别称、同名异人和被上下文误触发的身份分类。
- 保持正式重建只覆盖当前已完成的 71 本书，避免扫入后续全集书目。

主要修正
- 周作人：从“亲属”主分类改为“学术 / 诗文出处 / 师生 / 历史类比引用 / 神交引用”。本书语境是章太炎学生名单和文学史引用，不是李敖亲属线。
- 李传理：改为“出版 / 创作资料协助”。本书只是远流出版团队协作，不挂“诉讼 / 证人见证”。
- 宋恕：补为“学术 / 诗文出处 / 历史类比引用 / 神交引用”，避免被“表示异议”等邻近词带成公共论战。
- 徐敬业：拆分同名异人。本书的唐代徐敬业改为“徐敬业（唐代）”，分类为“政治异议者 / 军事人物 / 历史类比引用 / 神交引用”；原“徐敬业”保留给书简债权名单中的现代同名人物。
- 元稹：本书未出现，来自“无微之不续”误触元稹字“微之”，已在本书排除。
- 光绪：本书多为“光绪某年 / 光绪末年”的年号用法，已在本书排除，不影响其他书中真实光绪节点。
- 吕晚村、汪龙庄、洪北江：分别并回吕留良、汪辉祖、洪亮吉，避免字号/书名别称形成重复节点。
- 赵明诚：改为文学史人物主身份“学术 / 诗文出处 / 历史类比引用 / 神交引用 / 婚姻相关”，不再由“嫁给”触发成单一姻亲节点。

校对经验
- 历史文化类里，书名格式“某人：《某号先生文集》”很容易把“某号”抽成独立人物；优先判断是否为作者别号，并入正名。
- 字号别名要警惕误触普通句子，例如“无微之不续”会触发“微之 -> 元稹”。
- 同名异人要拆，不要为了“不重复”把不同历史层级的人硬合并；本轮“徐敬业”和“徐敬业（唐代）”就是这种情况。
- 现实协作人物不要被证据词带成诉讼线。本书出版协作线应优先保留“出版 / 创作资料协助”。
